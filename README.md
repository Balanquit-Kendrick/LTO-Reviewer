# 🚗 LTO Driving Examination Reviewer

A simple, browser-based **LTO Driving Licensure Examination reviewer** designed to help aspiring drivers in the Philippines prepare for the **LTO written exam**. This project is lightweight, easy to use, and built with **pure web technologies**—no frameworks, no backend.

---

## 📘 Project Description

The **LTO Driving Examination Reviewer** is a web application that simulates the actual LTO written exam experience. It presents randomized questions one at a time, supports both single-answer and multiple-answer questions, and provides a review of answers after exam submission.

This project is ideal for students, self-learners, and developers looking for a practical exam reviewer or a reference for building quiz-based web applications using **HTML, CSS, and vanilla JavaScript**.

## ✨ Features

- 📋 **Randomized Exam Questions**  
  Questions are randomly selected and shuffled on every attempt for a realistic exam experience.

- 🧠 **One Question at a Time**  
  Keeps users focused by displaying only one question per screen.

- 🔘 **Smart Answer Input**  
  Automatically uses:

  - **Radio buttons** for single-answer questions
  - **Checkboxes** for multiple-answer questions

- 🔍 **Answer Reviewer**  
  After submission, users can review:

  - Correct answers
  - Incorrect selections

- 📊 **Score Calculation & Results**  
  Displays the total score and overall exam result after completion.

- 📧 **Email Notifications**  
  Get notified via email whenever someone starts taking the examination.
  - Easy-to-configure email settings
  - Automatic notifications with timestamp and exam details
  - Powered by Getform for reliable delivery

---

## 🛠 Technologies Used

- **HTML** – Structure and layout
- **CSS** – Styling and visual presentation
- **JavaScript (Vanilla)** – Exam logic, question handling, scoring, and interactivity
- **Getform** – Form backend service for email notifications
